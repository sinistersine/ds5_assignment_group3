## DATA SCIENCE 5

Welkom bij onze **Data Science 5 (DS5)** repository! 📊🐍

In deze repository staan onze opdrachten, analyses en projecten voor DS5. Hier wordt data verzameld, verwerkt, geanalyseerd en natuurlijk gevisualiseerd.

### Benodigdheden

Om de code uit deze repository te kunnen uitvoeren heb je het volgende nodig:

* 🐍 Python
* 📓 Jupyter Notebook Extension
* 🐼 Pandas
* 🔢 NumPy
* 📊 Matplotlib
* 🧪 SciPy

Benodigdheden installeren:

```shell
pip install pandas numpy matplotlib scipy jupyter
```

### Installatie

Clone de repository naar je eigen computer:

```shell
git clone <repository-url>
```

Ga vervolgens naar de projectmap:

```shell
cd DS5
```

Start Jupyter Notebook:

```shell
jupyter notebook
```

### Vebruik

Open het gewenste `.ipynb`-bestand in Jupyter Notebook en voer de cellen uit.

Oftewel:

```python
data = load_data()

data = clean_data(data)

analysis = analyse(data)

visualise(analysis)

print("Data Science geslaagd! 🎉")
```
